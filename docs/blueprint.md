# **App Name**: DayWise

## Core Features:

- Task Input: Allow users to input and save tasks for the day.
- Task Display: Display tasks in a clear, prioritized manner.
- Schedule Suggestion: Suggest a schedule for the day based on the user's input tasks and priorities, using a tool to assess task duration and importance.

## Style Guidelines:

- Primary color: Calm blue (#64B5F6) for focus and clarity.
- Secondary color: Light grey (#E0E0E0) for a clean background.
- Accent: Teal (#26A69A) for task highlights and completion indicators.
- Clear and readable font for task descriptions and time slots.
- Simple, intuitive icons to represent different task categories (e.g., work, personal, errands).
- Clean and organized layout with clear visual separation between tasks and time slots.

## Original User Request:
An app that helps me plan my day in flutter
